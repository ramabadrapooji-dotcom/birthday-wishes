2. backcover.jpg 
3. bg-p3.jpg
4. photo-inside-bg-1.jpg
5. photo-inside-bg-2.jpg
6. photo-p1.jpg
6. photo-p2.jpg
7. photo-p3.jpg
... 
all the way to:

The AI Face-Framing logic in the code will automatically center on the faces and upper bodies, so you don't need to manually crop them to fit perfectly!

If any photo is missing, the magazine will gracefully show a placeholder "AI Face-Framing Photo Slot". 

Note: Ensure the file extensions are exactly ".jpg" (lowercase).
